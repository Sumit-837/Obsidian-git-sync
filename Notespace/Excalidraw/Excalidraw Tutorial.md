## Text Elements
Some basic handy features of Excalidraw: Showcase ^7nft8fqz

1. OCR (by taskbone)  ^mIiPcb4E

Converts Handwritten text into typed. 

- Should be enabled from excalidraw plugin's miscellaneous settings

- use: type "ocr" in the command pallate and select it, then the text goes to your clipboard, paste it manually. ^vioL0ubi

2. Grid: Add grids in background by toggling grids on from  the menu by right clicking on blank canvas


3. Snap to objects: turn this on from the same menu to get better object connection ^znYxNoYD

4. Stencil Library ^28MwBOyQ

Use: Summon Images/ shapes.

Access from right bar, library option ^XRwIgnAC

Add community libraries:
- Go to the site by clicking "Browse libraries". 
- Download a library.
- Then add it by click on the 3 dots in library panel > open >select the downloaded library  ^mesik3ea

Make Your own design and add in the library:

select the design, by right click "add to library" ^ETgY9gdE

Insert Files from Vault: 
By right clicking > Insert any file  ^bgzzeLL7

5. Linking ^E71Lx8wL

Insert Web elements:
copy the url, and simply paste it in the canvas.
For images: drag and drop ^M6J6gdJf

Inserting PDFs/ Markdowns ^Ot0ycqNq

Add each page as image for  batter marking ^kDXF5xCS

Add as embeded:
You can scrool through the full pdf , but not mark ^Swx82nlA

Mask & Crop Elements ^kcYubOJ6

With Exaclidraw's Crop & mask Feature.
Right panel> obsidian button> Insert actions> crop and mask ^PbvHTbJe
