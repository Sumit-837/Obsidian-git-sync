# loops
## Exit Control Loop:
The condition is checked _after_ the loop body is executed.This means the loop body is guaranteed to run at least once.
### Do-while loop:
Syntax:
```c
do {
	body;
} while(condition);
```
## Entry Control Loops:
The condition is checked _before_ the loop body is executed.
### While loop:
Syntax:
```c
while(condition) {
	body;
}
```
### For loop
Syntax: 
```c
for(initialization; condition; increment) {
	body;
}
```
